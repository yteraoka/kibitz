# リポジトリのコードは、資格情報を持たない別ジョブで実行する

- **状態**: 採用 (2026-09-24)
- **関連**: Phase 8 / [ADR-0014](0014-worker-pool-and-self-managed-scaling.md) / [ADR-0002](0002-gcp-first-single-tenant.md) / [security.md](../security.md)

## 背景

実装モードは書いたコードをビルドしてテストする。**つまり任意のコードを実行する。**

現在のワーカーが持っているもの:

| | |
| --- | --- |
| GitHub App の秘密鍵 | リポジトリの読み書き |
| GitLab / Azure DevOps のトークン | 同上 |
| Vertex AI の ADC | モデル呼び出し (= 課金) |
| Firestore | 冪等性の記録とロック |
| Pub/Sub | キュー |

**テストファイルは、PR を開ける人が誰でもコードを置ける場所である。** そこで
`os.ReadFile("/proc/self/environ")` を書けば、上の全部が読める。

`worker.md` は gVisor / Firecracker を挙げていた。しかしそれは GKE を意味し、
worker pool を前提にした [ADR-0014](0014-worker-pool-and-self-managed-scaling.md)
と、GKE 向け Helm chart を保留した判断に反する。

## 決定

**ビルドとテストは、権限を何も持たない専用サービスアカウントの Cloud Run ジョブで実行する。**

- ワークスペースを tar にして 1 つのバケットの 1 つのプレフィックスに置く
- ワーカーがジョブを 1 実行起動し、そのプレフィックスだけを渡す
- ジョブはツリーを展開し、`commands_allow` のコマンドを実行し、結果を JSON で書き戻す
- ワーカーは結果を読み、**通っていなければ PR を作らない**

## 理由

**ジョブのサービスアカウントは何の役割も持たない。** バケットの 1 プレフィックスだけ。
敵対的なテストがメタデータサーバーに到達してトークンを取っても、**そのトークンで
できることが無い。** これが「他人のテストスイートを走らせてよい」根拠である。

**ホストの分離は既に済んでいる。** Cloud Run はコンテナを gVisor 上で動かす。
この ADR が解く必要があるのは残り半分、つまり**kibitz 自身の資格情報**だけ。

**仕様を満たせる。** 「テスト失敗なら PR を作らない」は、PR を作る前に検証が
終わっている必要がある。リポジトリの CI に任せる案では PR が先にできてしまう。

**ジョブが知ることを最小にできる。** 渡すのはツリーとコマンドだけ。
どのリポジトリか、誰が指示したか、何のための変更かを**ジョブは知らない**。
知っても使い道が無く、他人のテストを走らせるプロセスには何も教えないほうがよい。

## 影響

**コマンドはシェルを通さない。** argv として直接起動する。`&&` や `|` を含む設定は
**受け付けずに拒否する** — 受け付けて無視すると「`go build` に妙な引数 3 つを渡して
成功扱い」になるため。リポジトリには 2 つのエントリに分けて書いてもらう。

**エージェント自身はビルドしない。** コードを書くエージェントの bash 権限は
与えない。ビルドを兼ねさせると、ワーカーの中でリポジトリのコードが動く。
書く側と試す側を分けるのがこの決定の骨である。

**環境変数は継承せず組み立てる。** ランナーは秘密を持たないが、kibitz が偶然
持っていた値に依存するビルドは、ここでは通ってリポジトリの CI で落ちる。

**出力は末尾を残して切る。** 失敗の理由は末尾に書かれている。1 万行の進捗を
出したビルドは、最初の 100 行で何も言っていない。

**イメージは distroless ではない。** リポジトリのツールチェーンが必要であり、
それが何かはリポジトリによる。同梱するのは Go だけで、TypeScript や Python の
リポジトリを持つデプロイは `Dockerfile.runner` から自分のものを作る。

**代償**: ワークスペースの受け渡し、ジョブの起動と待ち合わせ、バケットと IAM の
Terraform が要る。実装モードを使わないデプロイは `implement_enabled = false` の
ままで、これらは 1 つも作られない。
