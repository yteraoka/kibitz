# レビューの出力は日本語を既定にする

- **状態**: 採用 (2026-09-21)
- **関連**: `9256f2a` / `internal/reviewer/prompt.go`

## 背景

レビューコメントを何語で書くか。
モデルは指示しなければ、プロンプトかコードの言語に引きずられて揺れる。
同じリポジトリのレビューが日によって英語だったり日本語だったりするのは、
機能ではなく不具合に見える。

## 決定

**日本語を既定の出力言語とする。リポジトリ単位で上書きできる。**

- デプロイ全体の既定は `KIBITZ_LANGUAGE`。
- リポジトリは `.kibitz.yaml` の `review.language` で変えられる (ADR-0011)。
- プロンプトの中で言語を明示する。モデルの推測に任せない。

## 理由

このデプロイを読む人が日本語話者だから、という単純な理由である。
レビューは読まれてはじめて価値があり、
読む側の言語で書かれていないレビューは、読み飛ばされる。

**既定を持つこと自体**にも理由がある。
指定しなければモデルが選ぶが、その選択は入力に左右されるので安定しない。
どちらの言語を選ぶかより、**毎回同じ言語になること**のほうが効く。

リポジトリ単位で上書きできるようにしたのは、
コントリビュータが日本語話者とは限らないリポジトリがあるため。
これはデプロイ側が縛る理由がない設定なので、一方向にはしていない (ADR-0011 と対照的)。

## 影響

- プロンプトの固定文 (`# 依頼`、`## 差分`、`レビュー対象:` など) も日本語。
  出力言語を英語にしても、この骨格は日本語のまま。
  これは意図的で、骨格は kibitz 自身の指示であって、レビューの成果物ではない。
- 通貨記号は価格設定に従う (ADR-0013)。
  円の金額にドル記号を付けるのは、記号が無いより悪い。
